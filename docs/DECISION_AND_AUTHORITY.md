# The decision this engine serves, and who owns it

A profiling engine without a named decision is a liability with a user interface. This document
names the decision, the authority and the accountability chain. Fill the bracketed fields; do not
leave this document in template state while the system ingests data.

human verification before partnership onboarding].

Human authority: [named role, not named person, so the document survives staff change]. This role
alone converts a provisional profile into an actioned one.

What the engine may do without human approval: nothing that changes an entity's status, visibility
or treatment anywhere downstream.

What a wrong profile costs, stated plainly: [the concrete harm, financial, reputational or physical,
to the profiled entity]. Written down so that the threshold for human review is set by the harm and
